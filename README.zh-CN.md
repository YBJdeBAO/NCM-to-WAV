# NCM to WAV

🌐 **语言：** [English](README.md) | 中文

一个基于浏览器的 `.ncm` 音频批量转换工具。工具会在本地读取 NCM 文件，在浏览器中解析并解密其中的音频流，再通过 Web Audio API 解码，最终封装为 WAV，并以 ZIP 分卷形式下载转换结果。

所有处理都发生在浏览器本地，文件不会上传到服务器。

## 🚀 在线体验

https://ybjdebao.github.io/NCM-to-WAV/

## ✨ 功能特性

- 支持拖拽选择多个 `.ncm` 文件。
- 支持 NCM 到 WAV 的批量转换。
- 使用 JavaScript 在浏览器本地完成处理。
- 使用 JSZip 打包转换后的文件。
- 自动分卷打包，每个 ZIP 最多包含 40 首转换后的音频。
- 下载队列机制，让连续下载更平滑。
- 为每个生成的 ZIP 分卷提供手动下载按钮。
- 转换列表会显示每个文件的处理状态。

## 📦 使用方式

1. 打开在线体验页面。
2. 如果浏览器提示，请允许该站点弹出窗口或连续下载。
3. 将 `.ncm` 文件拖入页面的上传区域，或点击上传区域选择文件。
4. 等待文件读取、转换和打包完成。
5. 下载生成的各个 ZIP 分卷。
6. 解压 ZIP 文件即可获得转换后的 `.wav` 文件。

## 🧩 技术概览

转换器主要使用：

- CryptoJS：用于 NCM 解析过程中的 AES 操作。
- Web Audio API：用于浏览器端音频解码。
- 简单 WAV 写入逻辑：将解码后的 PCM 音频序列化为 WAV 容器。
- JSZip：用于将转换后的文件打包为可下载 ZIP。
- CDN 版 Tailwind CSS：用于页面界面样式。

## ⚠️ 限制说明

- 浏览器内存存在限制，尤其是在处理大量文件或长音频时。
- 转换是否成功取决于浏览器能否解码解密后的音频流。
- 某些浏览器可能会阻止连续自动下载，需要手动允许弹窗或下载。
- WAV 文件通常比压缩音频格式大得多。
